## 本轮修复

- 登录成功后额外访问课程 API 域再保存 Cookie，降低 API 域 route/JSESSIONID 混用导致的课程为空。
- 登录页覆盖标题、`lg-title`、手机号/密码表单特征；失效会话不再伪装成 0 门课程。
- 作业列表兼容当前网页版 `overHidden2` 标题、`p.status` 状态和 `li[data]` 官方链接。
- 选定日期范围时未知截止时间不进入主列表；未知项由汇总提示单独展示。
- 作业缓存只在页面明确显示“暂无作业”时删除旧课程数据；网络失败、验证码和空解析都会保留旧缓存。
- 课程表支持日/周视图、手动添加、CSV/TSV/XLSX/HTML 预览导入和通用教务 WebView 导入。
- 课程提醒登记课前 30 分钟和前一天 20:00 准备提醒；课程通知默认保持到用户点击“知道了”，不自动在课后消失；用户开启精确模式后使用精确闹钟。
- 通知频道使用版本化高重要性频道，检测低重要性/静音频道并打开系统频道设置。
- Debug 包保留诊断日志，Release 包不写页面片段诊断日志。
- 未知截止时间使用黄色独立分区；已完成但仍未知截止时间的作业不进入主列表。
- 当前时间范围隐藏与永久隐藏使用不同范围键；临时隐藏不会取消账号的全局提醒。
- 课程广播使用 `goAsync()` 后台处理通知和滚动闹钟重建，避免课程较多时阻塞广播主线程。

## 通知验收边界

Android 官方 API 允许应用设置通知权限、频道声音/重要性和锁屏公开可见，但不能绕过用户的通知总开关、频道设置、勿扰模式、通知音量、锁屏隐私和厂商后台策略。当前模拟器的通知权限和作业频道声音已打开，但没有授予 `SCHEDULE_EXACT_ALARM`；目标手机黑屏锁屏时的实际扬声器声音、厂商后台保活和电池策略仍需在目标设备上验收。
